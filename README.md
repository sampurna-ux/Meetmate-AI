MeetMate AI

Meeting-to-Action Assistant

Problem Statement: PS03 – Meeting-to-Action Bot for Student Teams

About the Project: 
MeetMate AI is a project designed to help student teams convert meeting discussions into organised and trackable tasks.

It helps identify important decisions, action items, responsible team members and deadlines from meeting transcripts.


Features in Our Current Prototype:
- Meeting transcript input
- Basic task extraction
- Owner and deadline tracking
- Identification of missing owners and deadlines
- Editable task tracker
- CSV export
- Meeting report generation
- 

How It Works (Proposed Workflow)?

1. A team provides a meeting transcript.
2. An AI model analyses the discussion.
3. Important decisions and action items are extracted.
4. Missing owners and deadlines are flagged.
5. Tasks are organised and shared with the team.
6. Tasks can be stored and tracked.


Technologies:

- HTML, CSS and JavaScript – Prototype interface
- Gemini API – Planned integration
- n8n – Planned workflow automation
- Telegram Bot – Planned integration
- Google Sheets – Planned task storage


Current Status:

The current version is a standalone browser-based prototype that uses basic rule-based extraction. AI processing and external integrations are planned for further development.
